# Etiquetas

Las etiquetas son marcas flexibles que pones en las transacciones. Una categoría dice qué clase de gasto es algo; una etiqueta dice a cuál de tus cosas pertenece.

## Etiquetas o categorías

Una transacción tiene exactamente una [categoría](/documentation/categories) y cualquier número de etiquetas. Esa diferencia es la razón de tener las dos.

Tira de una etiqueta cuando un grupo de transacciones cruza categorías: un viaje que fueron vuelos, restaurantes y taxis; una reforma que fueron herramientas, muebles y un fontanero; los gastos que vas a facturar a un cliente.

Tira de una categoría cuando quieras que la transacción aterrice en algún sitio de tus informes. Las etiquetas no aparecen en el informe de flujo de caja: son para filtrar y para presupuestos.

## Cómo se gestionan

Las etiquetas viven en **Configuración → Etiquetas**. Cada una tiene un nombre y un color, y la lista se puede filtrar por nombre cuando ya hay suficientes para necesitarlo.

![La pantalla de ajustes de etiquetas, con cada etiqueta y su distintivo de color junto a un botón para crear una nueva](/docs/documentation/labels-settings.png)

Hay veinte colores para elegir. El color es lo que hace que una etiqueta se lea de un vistazo en la lista de transacciones, así que merece un momento de reflexión: un color por área de tu vida funciona mejor que veinte etiquetas en veinte colores.

También puedes crear una etiqueta sin salir de la transacción que estás editando. Después aparece en la lista de ajustes como cualquier otra.

## Para qué sirven las etiquetas

- **Filtrar.** Filtra la lista de transacciones por etiqueta para ver todo lo que pertenece a un proyecto, un viaje o una persona.
- **Filtros guardados.** Una etiqueta más un rango de fechas, guardado, es un informe que abres con un clic.
- **Presupuestos.** Un presupuesto puede seguir una etiqueta en lugar de una categoría, que es la forma de poner techo a algo que cruza categorías.
- **Reglas de automatización.** Una regla puede poner una etiqueta además de asignar una categoría, así que un comercio recurrente se etiqueta solo.
- **Acciones masivas.** Selecciona un grupo de transacciones y etiquétalas todas de una vez.

## Borrar una etiqueta

Borrar una etiqueta la quita de las transacciones que la llevaban. Las transacciones no se tocan (sus importes, fechas y categorías siguen igual), pero todo lo que coincidiera por esa etiqueta deja de coincidir, incluido un presupuesto que la siguiera.

Si el problema es que la etiqueta está mal nombrada, renómbrala. Renombrar mantiene todas las transacciones atadas.

## Preguntas frecuentes

### ¿Cuántas etiquetas debería tener?

Las suficientes para acordarte. Una etiqueta que tienes que buscar es una etiqueta que no vas a usar, y una etiqueta sin usar hace la lista más difícil de leer para las que sí usas.

### ¿Una transacción puede tener dos etiquetas?

Sí, tantas como quieras. Ésa es la diferencia con las categorías.

### Hay una etiqueta que yo no puse en una transacción.

La ha puesto una regla de automatización. La regla que lo hizo está en [Reglas de automatización](/documentation/automation-rules), donde puedes cambiar o quitar la etiqueta de sus acciones.
