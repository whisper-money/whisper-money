# Storylines

The storyline was picked before this project started (storyline B of the
custom dashboards launch). The other two are separate films in
`videos/dashboards-one-of-a-kind/` and `videos/dashboards-one-per-person/`.

## B. Infinite zoom / «Zoom infinito» (built)

- **Device and form:** the result first, as an endless zoom: each widget opens
  into the next person's request.
- **What the viewer sees and feels:** a finished chart from a real dashboard.
  The camera dives into one of its bars and finds a sentence someone typed; the
  sentence becomes the code an agent wrote, the code becomes a new widget, and
  the camera dives again. Three asks later it pulls all the way back to the
  dashboard they built. The feeling: none of this was a template.
- **First two seconds:** frame 0 is the real "weekly shop" widget filling the
  frame on a flat grey field. At 0.4 s the camera starts to push into its
  tallest bar; by 1.6 s the bar's green is the whole frame.
- **Beats:** chart → dive → ask 1 (takeaway, weeknights vs weekends) → code →
  widget → dive → ask 2 (when the car is paid off) → code → widget → dive →
  ask 3 (kids' activities per term) → code → widget → pull back to the whole
  dashboard → claim → end card.
- **Look:** one flat colour field per cycle, each the colour of the mark the
  camera dove into (emerald, amber, pale blue), real light-mode UI at the
  centre at 60–80% of the frame width. No glow, no dark void.
- **Sound:** a kick pulse that speeds up on every dive (92 → 112 → 132 BPM),
  then stops and releases on a low impact at the pull-back.
