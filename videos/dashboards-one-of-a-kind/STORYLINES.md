# Storylines

The orchestrator picked storyline A for this project. The other two are built as
separate films (`videos/dashboards-infinite-zoom/`, `videos/dashboards-one-per-person/`).

## A — "Nobody else has this widget" / «Nadie más tiene este widget» (built)

- **Device:** a very specific question that no template would cover.
  **Form:** one frame that rebuilds. One real Whisper Money dashboard keeps
  rearranging itself and never leaves the frame.
- **What the viewer sees and feels:** a person asks a question about their own life
  (the dog, the morning coffee, the Japan trip, the bike). Each question becomes a
  live widget on their dashboard. By the end the dashboard could only belong to them.
- **First 2 s:** the real "Just mine" dashboard in light mode with one widget
  (groceries) and an empty slot. The sentence "How much have I spent on the dog
  this year?" appears in that slot.
- **Beats:** the sentence → the agent writes the widget (its real code visible for
  a moment) → the widget lands in the slot with live data → three asks, each more
  specific, each spawning its own widget (coffee before 10am, what's left for Japan,
  fuel vs. bike) → the grid reshuffles into the person's dashboard → claim "No
  widget existed until you asked for it" → end card (the bird performed in,
  whisper.money, the call to action).
- **Look:** the app's real UI in light mode, full frame; the brand accent only on
  the widget being born.
- **Sound:** a soft rhythmic bed at 96 BPM, a click each time a widget lands.
